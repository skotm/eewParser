# JmaEewParser

気象庁の緊急地震速報(警報)の公開履歴から、MeteoQuakeで再生できるEEWファイル(`.eew.json`)を作るツールです。
サーバーは不要で、すべてブラウザ内で動きます(GitHub Pagesで公開できます)。

## 使い方

1. 気象庁の公開履歴の一覧を取り込みます。ブラウザから直接取得できない時は、一覧ページをHTMLとして保存して読み込みます。
   <https://www.data.jma.go.jp/eew/data/nc/pub_hist/index>
2. 事例を選び、詳細ページを解析します(これも、保存したHTMLを読み込めます)。
3. 「確認が必要な点」を見て、`.eew.json` を保存します。ファイル名は `YYYYMMDD_震央名M規模.eew.json` です。
4. MeteoQuakeの設定「リプレイ」で、このファイルを読み込みます(複数可)。

対象は警報が発表された事例だけです。予報だけの事例は、気象庁の公開履歴にありません。

## 出力(JSON 1.2.0)

従来のフィールド(`event` / `reports` / `sourceTables`)に加えて、`normalized` を出力します。MeteoQuakeが読むのはこの部分です。

- `event`: 地震の識別子、発生時刻(`originTimeMs`、UTCミリ秒)、地震波検知時刻(`detectionTimeMs`)、震源名、緯度・経度・深さ・M
- `reports[]`: 報ごとの発表時刻(`issuedAtMs`)、震源、最大震度(`maxIntensityKey`)、地域ごとの予想震度、長周期地震動階級、最終報・キャンセル報の印
- 震度は震度キー(`"0"`〜`"4"`、`"5-"`=5弱、`"5+"`=5強、`"6-"`、`"6+"`、`"7"`)で持ちます。
- 報の発表時刻は「地震波検知時刻 + 経過時間」(0.1秒単位)です。検知時刻が無い時は、提供時刻(1秒単位)で補います。
- 予報区ごとの予測が無い初期の報は、最大震度だけを持ちます(`maxIntensityOpenEnded: true`)。
- 抽出できなかった項目は推測せず、`normalized.warnings` に出します。

### 発生時刻が分単位の事例
気象庁の予報の履歴ページは、発生時刻が分単位です。この場合、既定では秒は0として出力し、警告を付けます。画面に出る「秒」の入力欄で秒(0以上60未満、小数可)を指定すると、その値を発生時刻に加え、警告も「手入力」に変わります。
MeteoQuake側で、検知時刻の少し前と推定して使います。

### 震源の緯度・経度が取れない場合
表の見出しと値の対応から取れない時は、ページ内の「北緯◯度」「東経◯度」(度分・N/E表記も可)から探します。
それでも取れない時は、画面に入力欄が出るので、公式ページを見て手入力してください(警告に「手入力」と残ります)。

## 開発

```bash
npm install
npm run dev
npm test   # 正規化ロジックの単体テスト(Node 22.6+)
```

`main` にpushすると、`.github/workflows/deploy.yml` でGitHub Pagesに公開されます。
